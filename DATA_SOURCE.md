# Data Source

## Main Dataset

This project uses public data from Stats NZ Agricultural Production Statistics.

Dataset table used:

**Kiwifruit canopy area hectares by variety, 2007–2024**

Source page:

```text
https://www.stats.govt.nz/information-releases/agricultural-production-statistics-year-to-june-2024-final/
```

## Notes

The CSV file in this project was manually created from the Stats NZ table for learning and analysis purposes.

The original raw dataset is stored in:

```text
data/kiwifruit_canopy_area.csv
```

The processed analysis-ready dataset is stored in:

```text
data/kiwifruit_canopy_area_processed.csv
```

## Purpose

This dataset is used to analyse long-term changes in New Zealand kiwifruit canopy area across green, gold, and other kiwifruit varieties.
