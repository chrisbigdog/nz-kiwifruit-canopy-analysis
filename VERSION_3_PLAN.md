# Version 3 Plan: Deploy Streamlit Dashboard Online

## Goal

Deploy the Streamlit dashboard online so anyone can open the project through a public web link without installing Python or running the app locally.

## Deployment Platform

Streamlit Community Cloud

## Current Project Readiness

The project already includes:

- Public GitHub repository
- Streamlit app file: `streamlit_app.py`
- Python dependencies in `requirements.txt`
- Data files inside the `data/` folder
- Working local Streamlit dashboard

## Deployment Steps

1. Confirm the GitHub repository is public
2. Confirm `streamlit_app.py` works locally
3. Confirm `requirements.txt` includes all needed packages
4. Sign in to Streamlit Community Cloud
5. Create a new app from the GitHub repository
6. Select the correct branch: `main`
7. Select the correct app file: `streamlit_app.py`
8. Deploy the app
9. Test the public app link
10. Add the live dashboard link to the README
11. Commit and push README update
12. Create Version 3 release

## Target Release

v3.0.0 - Online Streamlit Dashboard Deployment
