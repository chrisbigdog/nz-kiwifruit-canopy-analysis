# Version 2 Plan: Interactive Streamlit Dashboard

## Goal

Create an interactive Streamlit dashboard for the New Zealand Kiwifruit Canopy Area Analysis project.

The dashboard will make the project easier to explore and more useful for people viewing the project on GitHub.

## Planned Features

- Display project title and overview
- Load the processed kiwifruit canopy dataset
- Show key metrics for the latest year
- Display canopy area trends by variety
- Display percentage share trends by variety
- Display total canopy area by variety
- Show simple written insights
- Add dashboard run instructions to README
